# Voxel 4X · 大陆纪元 —— 游戏设计规格（权威文档）

> 本文档是 Voxel 4X 游戏的唯一权威规格。各阶段子代理必须按本文档实现，验收以本文档 + 类型检查 + 构建为准。
> 项目位置：`web/aitoolkit/src/games/voxel4x/`。前端约定：无 emoji、暗色主题、注释用中文、`v-text` 不用 `v-html`、用全局 CSS 变量（--accent/--muted/--dim/--line/--line-strong/--green/--amber/--red）。

## 0. 玩法总览
浏览器端 **4X 大战略 + Victoria 3 式经济模拟**。无限世界，探索即加载（chunk 按需生成 + IndexedDB 持久化）。纯经济，**无战斗**。
四大支柱：eXplore（无限世界探索）、eXpand（城市自动开发扩张）、eXploit（生产建筑 + 市场供需）、经济（每城独立市场 + 订单物流）。

## 1. 世界与地图
- 无限地形：噪声生成，坐标支持任意正负值（实际范围 ±2^30 内视为无限）。由阶段 1 的 `terrain.ts` + `terrain.worker.ts` 提供。
- 生物群系 22 种（沿用 map.html 分类），决定格子天然资源潜力。
- 瓦片金字塔 LOD：主线程持有 LRU 瓦片缓存，worker 离线生成 chunk，Transferable 传二进制；主线程按视图模式上色。
- 迷雾：以 chunk 粒度记录已探索状态；单位/城市视野解锁；未探索区域渲染为黑雾（阶段 3）。
- 持久化：IndexedDB 两个 objectStore —— `save`（游戏存档）与 `chunks`（已探索地形，阶段 4）。

## 2. 资源系统
每个城市有**独立资源库存**。全局资源类型：
| id | 名称 | 基价 | 说明 |
|---|---|---|---|
| food | 食物 | 1.0 | 养人口，人口增长 |
| wood | 木材 | 1.2 | 建造 |
| stone | 石料 | 0.8 | 建造 |
| iron | 铁矿 | 2.0 | 工业 |
| coal | 煤炭 | 1.5 | 工业 |
| tools | 工具 | 6.0 | 加工品（消耗木+铁） |
| cloth | 布 | 5.0 | 加工品 |
| money | 金币 | — | 城市资金（非贸易品） |
| science | 科技点 | — | 研究（非贸易品） |

劳动力（labor）非库存资源，由人口提供，建筑按生产方式雇佣。

## 3. 市场与价格机制（Victoria 3 式）
每个城市是**独立本地市场**，每 tick（约 1 秒）计算：
- 买入需求 `buy` = Σ 城市内建筑消耗单 + 人口基本需求
- 卖出供给 `sell` = Σ 城市内建筑产出单 + 库存可卖量
- 价格公式（V3）：`price = base × (1 + 0.75 × (buy − sell) / (buy + sell))`，clamp 到 `[0.25, 1.75] × base`；当 buy+sell=0 时价格回到 base。
- 成交：`amount = min(buy, sell)` 按当前价成交；差额即供需缺口（短缺→价格升→吸引订单）。
- 城市可对市场**自动买卖**（阶段 4 完善）：缺货自动买、盈余自动卖，与订单物流联动。

## 4. 城市
```
City {
  id, name, x, y        // 中心格坐标（世界坐标）
  population            // 人口（劳动力池）
  foodStock             // 食物储备（喂人口）
  treasury              // 金币
  territory: Set<CellKey>   // 已开发格子集合
  buildings: Building[]      // 城内生产建筑
  market: { [res]: { stock, buy, sell, price } }  // 独立本地市场
  devQueue               // 开发/建造队列
  productionQueue        // 生产队列（建筑/单位）
}
```
- 人口：建筑雇佣（就业率）；食物满足人口 → 人口增长；缺食 → 停滞/小幅下降。
- 城市初始有：人口 10、初始食物/木材/石料各 50、金币 100。

## 5. 生产建筑与生产方式
建筑建在**城市领土格**上，受地形要求限制（非法格不可建/开发）。
| 建筑 | 输出 | 输入 | 地形要求 | 生产方式示例 |
|---|---|---|---|---|
| 农场 farm | food | — | 肥沃（草原/草甸/冲积/河岸） | 粗放(1食/1工)/集约(3食/3工) |
| 伐木场 lumber | wood | — | 森林 | 普通/轮伐(+木/需维护) |
| 采石场 quarry | stone | — | 山地/岩石 | 普通/爆破(+石/需coal) |
| 铁矿 iron_mine | iron | — | 山地含矿 | 普通/深井(+铁/需coal) |
| 煤矿 coal_mine | coal | — | 山地 | 普通/深井 |
| 工坊 workshop | tools | wood+iron | 平坦 | 手工/机械(需coal) |
| 织布坊 weaver | cloth | —（或需输入） | 平坦 | 手工/机械 |
| 粮仓 granary | +食物容量 | — | 平坦 | — |
| 市场 market | +贸易吞吐/库存容量 | — | 平坦 | — |
| 学校 school | science | — | 平坦 | — |
| 工坊 mill | +生产效率 | — | 平坦 | — |

每个建筑一个 `productionMethod` 可切换，改变输入/输出组合与雇佣数（阶段 3 完善切换 UI，阶段 2 先实现默认方式）。

## 6. 开发与扩张（用户指定机制）
- **城市自动在周边格子上建造生产建筑，开发即扩张**：城市领土 = 已开发格子的连通范围。
- 自动决策：每 tick，城市检查领土边缘的相邻格，按"当前资源缺口 + 地形匹配"挑选最优格子开发，消耗金币+时间后该格纳入领土并在其上建对应生产建筑（如缺食物→优先开发肥沃格建农场）。
- 玩家可干预（阶段 3 起）：暂停自动开发、指定重点资源、手动指定某格开发。
- 开发冷却：每次开发需等待（如 3 秒 + 依距离增长）。

## 7. 订单物流（阶段 4，用户指定机制）
- **需求城市缺货 → 自动发布采购订单** `{ res, qty, price }`（price 为出价，高于本地市价留出利润空间）。
- 商队（caravan 单位）**自动接单**：空闲商队选择利润最高的订单 → 移动到供给城市装货 → 移动到需求城市交货收款。盈余 = 卖价 − 买价 − 运输成本。
- 玩家可手动：发布订单、指派商队、调整出价。
- 运输：距离决定时间与成本；商队有运力上限。

## 8. 单位（无战斗，可移动）
- 侦察兵 scout（阶段 3）：移动探索迷雾，扩大已探索范围。
- 开拓者 settler（阶段 3）：消耗资源后在目标格建立新城市。
- 商队 caravan（阶段 4）：跑订单物流。
- 单位在地图上以图标绘制，右键/点击移动（阶段 3 起）。

## 9. 科技树（阶段 3）
- 时代：远古 → 古典 → 中古 → 工业 → 现代 → 星际。
- 科技由学校产出 science 点研究；每项科技解锁建筑/生产方式/效率。
- 示例：石工术(解锁采石场)→铁器(解锁铁矿/工坊)→机械(解锁机械生产方式)→...

## 10. 目标与里程碑
- 开放式沙盒 + 里程碑：城市数、总人口、最高时代、累计探索面积。

## 11. 存档（阶段 4，IndexedDB）
- DB 名 `voxel4x`，版本 1；objectStore `save`（key 'game'，JSON：城市/资源/科技/单位/已探索 chunk 表/相机/种子/时间戳）与 `chunks`（key `${L}:${tx}:${ty}`，二进制地形数据）。
- 自动存档节流（约 30 秒）+ 页面隐藏/离开强制存档 + 离线恢复（按上次离线时长补算产出）。

## 12. UI 结构（Voxel4xView.vue）
- 全屏 canvas（阶段 1 完成渲染/相机/小地图/悬停/视图模式）。
- 顶部 HUD：当前选中城市资源条（食物/木材/石料/铁/煤/工具/布/金币/科技点/人口）。
- 左/右侧面板：城市市场（各商品价格/库存/供需）、建筑列表与生产方式、开发控制、订单列表、科技树、单位列表。
- 底部状态栏：坐标/缩放/瓦片缓存数/种子。
- 全屏规则：根元素 class `voxel4x`，global.css 追加 `.app-content:has(.voxel4x) { padding: 0 }`。

## 13. 分阶段实施范围
- 阶段 1（已完成）：无限地形引擎 + worker + 渲染 + 相机 + 小地图 + 悬停 + 视图模式 + 路由/卡片。
- 阶段 2：城市对象、劳动力池、独立市场（供需+价格）、生产建筑（含地形要求）、自动开发扩张、tick 循环、资源 HUD、选中城市面板。
- 阶段 3：迷雾、侦察兵/开拓者单位（移动+探索+建城）、科技树（时代+解锁）、开发干预（暂停/指定）。
- 阶段 4：订单物流（自动+手动）、商队单位、跨城套利、IndexedDB 存档/恢复、性能优化、整体打磨。

## 14. 验收标准（每阶段）
1. `cmd /c "npx vue-tsc --build --noEmit"`（workdir web\aitoolkit）零错误。
2. `cmd /c "npx vite build"`（workdir web\aitoolkit）成功。
3. 代码无 emoji、注释中文、暗色主题、无 `v-html` 滥用。
4. 机制符合本文档核心条款（价格公式、自动开发、订单物流、存档恢复）。
5. 每阶段交付后浏览器可试玩（现有 GUI http://127.0.0.1:4091 刷新验证，需 `pnpm run dev:web` 重建前端产物）。
